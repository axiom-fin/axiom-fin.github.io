# axiom-fin.github.io

Project page for "Towards Financial World Modeling: An Open Efficiency Question", an accepted Grand Challenge paper
at the AXIOM workshop (NeurIPS 2026). The layout follows the CLEAR project page (Academic Project Page Template).
`index.html` is the page, `static/` holds the stylesheets, team photos and the camera-ready PDF. The hero animation is
an illustration and does not show data from the paper.
